# 2일차 조사: 유후인 (온천과 아이 체험)

일정: 유후인 산책, 점심, 아프리칸 사파리, 온천, 가이세키

> 아래 정보는 공식 사이트와 여행 블로그 기준이며 최신이 아닐 수 있습니다. 방문 전 공식 사이트에서 확인하세요.

## 1. 규슈 자연동물공원 아프리칸 사파리 (아이 체험)

공식 사이트 기준

| 항목 | 내용 |
|---|---|
| 운영시간 (3~10월) | 접수 9:00~16:00, 개장 9:30, 폐장 16:30 |
| 운영시간 (11~2월, 1월 하순 해당) | **접수 9:30~15:00, 개장 10:00, 폐장 15:30** |
| 휴무 | 연중무휴 (우천 포함) |
| 입장료 | 고등학생 이상 2,600엔, 4세~중학생 1,500엔 |
| 정글버스 | 입장권과 별도 구매, 1,100엔 (블로그에 따라 1,500엔이라는 글도 있어 확인 필요) |

- 주말과 공휴일은 정글버스가 일찍 마감될 수 있어 온라인 예약 권장
- **일정 조정 필요**: 겨울철 접수 마감이 15:00, 폐장이 15:30이라, 기존 일정의 13:00 도착은 빠듯함. 유후인에서 차량 약 1시간 10분이므로 **오전에 출발해 점심 전후에 도착**하는 쪽이 안전함
- 확인할 것
  - 정글버스 예약과 8명 좌석, 3세 이하 요금
  - 렌터카 밴으로 자가 차량 입장이 가능한지
  - 유모차 반입과 이동 편의

## 2. 유후인 마을 산책

- 유노츠보 거리: 길이를 800m(약 70개 점포)로 보는 글과 유후인역~킨린코 호수 1.5km로 보는 글이 있음 → **도보 30분 제한을 고려해 구간을 나눠야 함**
- 메인 도로는 평탄하게 포장되어 있어 이동이 편하다는 소개가 있음
- 플로럴 빌리지: 유노츠보 거리 끝에서 도보 3~5분이라는 글이 있음. 동화 같은 마을과 동물 구경이 있어 아이에게 적합
- 대표 간식
  - 비스피크(B-speak) 롤케이크: 예약 필수
  - 긴상 크로켓: 100엔대부터
  - 유후인 푸딩

## 3. 주차

- 유노츠보 거리에는 전용 주차장이 없어 유후인역 주변 유료 주차장을 이용해야 함
- 플로럴 빌리지 전용 주차와 입장료는 **확인되지 않음**
- 10인승 밴이 들어갈 수 있는 높이와 면적의 주차장 확인 필요

## 4. 식사

- 웨이팅이 긴 곳은 피하는 것이 좋다는 의견이 많음
- 유모차 진입이 편한 평지 정원 식당이나 다다미 온돌방(바닥에 앉을 수 있는) 식당이 어린 아이 동반에 적합
- 8명이 함께 앉을 수 있는 식당과 아이용 메뉴가 있는 구체적인 식당은 **확인되지 않음 (추가 조사 필요)**
