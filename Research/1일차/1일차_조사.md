# 1일차 조사: 후쿠오카 도착 → 유후인

일정: 공항 도착, 렌터카 픽업, 점심, 유후인 이동, 료칸 체크인, 온천, 가이세키

> 아래 정보는 대부분 여행 블로그와 예약 사이트 기준이며 최신이 아닐 수 있습니다. 예약 전 공식 사이트에서 확인하세요.

## 1. 렌터카 (10인승 이상 밴)

- 검색에서 후쿠오카공항의 **10인승 하이에이스 그랜드캐빈 대여를 직접 확인한 자료는 없음** (확인 필요)
- 후쿠오카공항에는 여러 렌터카 업체가 있고 승합차 차종 분류가 있으나, 하이에이스 포함 여부는 업체 페이지에서 확인해야 함
- 10인승은 수요가 적어 일찍 예약해야 함
- 대안: 운전기사 포함 전세 차량(KKday 등)에 5·7·10·14인승 옵션이 있음. 단, 운전자가 본인 1명인 상황에서는 부담을 줄이는 선택지가 될 수 있음
- 확인할 것
  - 닛폰·도요타 등 주요 업체의 후쿠오카공항점 승합차 페이지에서 차종명과 정원
  - 국제운전면허증으로 대여 가능한지, 면허 조건
  - 스터드리스 타이어 또는 체인 포함 여부 (1월 하순 유후인 대비)
  - 유모차와 캐리어 8명분이 실제로 실리는지 (10인승은 전원 탑승 시 짐칸이 좁을 수 있음)
  - 국제선 터미널에서 영업소까지 셔틀 이동 시간

### 추가 조사 결과 (렌터카)

- **로마카 렌터카**: 후쿠오카공항을 포함한 4곳에서 대여·반납 가능, 하이에이스 그랜드캐빈 10인승, **12시간 18,000엔(세금 포함)부터**, 24시간 접수와 비대면 수속. 보험 등 부대비용 포함 여부는 확인 필요
- 면허 조건이 업체마다 다름: 보통면허로 운전 가능한 최대 정원(10명) 차량으로 소개하는 곳도 있고, 상품 페이지에 "대형면허 필수"로 적은 곳도 있음. **본인은 대형면허가 있으므로 문제없으나 국제운전면허증에 해당 종류가 기재되는지 업체에 확인 필요**
- 참고 요금(오사카 지점, 후쿠오카와 다를 수 있음): 도요타렌타리스 신오사카 그랜드캐빈 12시간 23,760엔, 24시간 29,700엔
- 국제선 터미널 빌딩 1층에 렌터카 카운터가 모여 있음. 영업시간은 도요타 8:00~20:00, 타임즈 8:00~19:00 (1일차 도착 10:30은 가능). 일부 업체는 셔틀 픽업이 있고 대기 약 15분
- 닛폰·오릭스·도요타 후쿠오카공항점의 10인승 요금은 **확인되지 않음** (날짜를 입력해 공식 사이트에서 비교 필요)

## 2. 유후인 료칸 후보

> 8명이 함께 쓸 수 있는 객실을 확인한 자료는 없음. 객실 구성(큰 방 1개 또는 여러 방)은 료칸에 직접 문의해야 함

| 료칸 | 참고 가격(1박, 블로그 기준) | 특징 |
|---|---|---|
| 유후인 바이엔 | 40~50만 원대 | 유후다케 뷰, 넓은 정원, 3세대 가족에게 추천 |
| 쿠츠로기노야도 나나카와 | 60~70만 원대 | 전 객실 복층 + 노천탕, 아이 동반 휴식에 적합 |
| 세이코엔 | 30~40만 원대 | 한국인 직원 상주, 가성비, 아이와 처음 가는 료칸으로 추천 |

- 가격은 1박 기준 객실 또는 1인 기준이 글마다 다를 수 있어 **정확한 요금은 확인 필요**
### 추가 조사 결과 (8명 수용 객실)

| 료칸 | 객실 | 정원 | 비고 |
|---|---|---|---|
| **후키노야 (유후인온천 료관)** | 별채 '사토야' (단층, 노천탕 포함) | **8명** | 8명 기준 가장 직접적인 후보 |
| 후키노야 | 별채 '하나야' (2층, 노천탕) | 12명 | 인원이 더 많을 때 |
| 오야도 이치젠 | 방 2칸 연결 노천탕 별채 | 2~6명 | 8명에는 부족 |
| 유후인 별저 카제노모리 | 전 객실 노천탕 별채 | 확인되지 않음 | 총 8실 |

- 잇코텐, 호테이야, 코토 노 카신 등은 가족탕·객실 노천탕이 있으나 8명 수용 여부는 **확인되지 않음**
- 요금과 1월 하순 예약 가능 여부는 확인되지 않음 → 공식 사이트나 예약 사이트에서 날짜 입력 필요
- 후키노야 공식 사이트: https://www.fukinoya.com/ko/

### 선택 기준

- 단독 별채 또는 큰 객실(8명 수용)
- 유후다케 뷰 대욕장
- 어린이 식사(햄버그스테이크, 튀김, 우동 등 어린이 런치) 제공
- 방 식사가 어렵다면 연회장이나 개별 다이닝룸 안내 가능 여부
- **가족탕**: 대부분 당일 선착순 예약이라 체크인하자마자 예약하는 것이 좋음. 무료 전세탕이 넓은 곳 우선

## 3. 공항 근처 점심

- 국제선 터미널 근처의 아이 동반 식당 상호는 **확인되지 않음** (구글맵에서 직접 검색 필요)
- 공항 식당은 점심 피크에 줄이 길어지기 쉬움 → 이른 점심이나 피크 시간 회피 권장
- 국제선↔국내선 무료 셔틀 약 10~15분, 지하철은 국제선 터미널에 직접 연결되지 않음

## 4. 이동 (공항 → 유후인)

- 고속도로 약 1시간 30분~2시간 (일정 가정치)
- 휴게소 휴식 1회 포함
