# 구글 시트 저장소 설정 방법

GitHub Pages 웹앱에서 비용 정산을 가족이 함께 보고 입력하도록, 구글 시트에 저장하는 방법입니다.
소요 시간은 약 10분입니다.

## 1. 시트 만들기

1. https://sheets.google.com 에서 빈 스프레드시트를 만들고 이름을 `후쿠오카 여행 비용`으로 바꿉니다.
2. 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.

## 2. 코드 붙여 넣기

1. 왼쪽 파일 목록의 `Code.gs`를 열고 안에 있는 내용을 모두 지웁니다.
2. 이 폴더의 [Code.gs](Code.gs) 내용을 전부 복사해서 붙여 넣습니다.
3. 상단의 저장(디스크) 버튼을 누릅니다.

## 3. 비밀번호 정하기 (선택)

**비밀번호 없이 쓰려면 이 단계를 건너뛰세요.** 스크립트 속성을 하나도 만들지 않으면 웹앱 주소를 아는 누구나 비용을 보고 편집할 수 있습니다. 이미 속성을 만들었다면 아래 "비밀번호 없이 쓰기로 바꾸려면"을 보세요.

비밀번호를 쓰려면 코드에 넣지 않고 "스크립트 속성"에 넣습니다.

1. 왼쪽의 **프로젝트 설정(톱니바퀴)**을 누릅니다.
2. 아래쪽 **스크립트 속성**에서 **스크립트 속성 추가**를 누르고 두 개를 만듭니다.

| 속성 | 값 | 용도 |
|---|---|---|
| `EDIT_CODE` | 편집용 비밀번호 | 비용 추가, 삭제, 환율과 출발일 설정 |
| `VIEW_CODE` | 보기용 비밀번호 | 조회만 가능 (가족에게 공유) |

- 두 비밀번호는 서로 달라야 합니다.
- 6자리 이상으로, 다른 사이트에서 쓰지 않는 것으로 정하세요.

## 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 설정하고 **배포**를 누릅니다.
   - 설명: `비용 저장소`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 처음에는 권한 승인 창이 뜹니다. 계정을 고르고 "고급 > (프로젝트 이름)(안전하지 않음)으로 이동"을 눌러 허용합니다. 본인이 만든 스크립트라서 나오는 안내입니다.
5. 마지막에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 5. 주소를 웹앱에 연결

복사한 URL을 Claude에게 알려주세요. `app/sheet-url.txt`에 넣고 빌드해서 GitHub Pages에 반영합니다.

직접 하려면 `app/sheet-url.txt` 파일에 URL 한 줄만 적고 아래를 실행한 뒤 commit, push 하면 됩니다.

```
node app/build-pages.js
```

## 6. 사용

- Pages 주소를 열면 비용 탭에서 비밀번호를 물어봅니다.
- 보기용 비밀번호는 가족에게, 편집용 비밀번호는 입력을 맡은 사람만 사용합니다.
- 비밀번호는 각자 기기의 브라우저에만 저장됩니다. 더보기의 "로그아웃"으로 지울 수 있습니다.
- 시트에서 `expenses` 탭을 직접 열어 보고 고칠 수도 있습니다. (`payer`는 a=우리 가족, b=장인·장모, c=처제 가족)

## 비밀번호 없이 쓰기로 바꾸려면

1. Apps Script에서 `Code.gs`를 이 폴더의 최신 [Code.gs](Code.gs)로 바꿔 붙여 넣고 저장합니다.
2. **프로젝트 설정(톱니바퀴) > 스크립트 속성**에서 `EDIT_CODE`와 `VIEW_CODE`를 **둘 다 삭제**합니다.
3. **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포**로 새 버전을 배포합니다. (주소는 그대로입니다.)
4. 웹앱을 열면 비밀번호 없이 바로 비용이 보이고, 편집 버튼으로 입력할 수 있습니다.

나중에 다시 비밀번호를 걸고 싶으면 스크립트 속성을 다시 만들고 새 버전으로 배포하면 됩니다. 웹앱이 자동으로 비밀번호 입력 화면을 보여 줍니다.

## 코드를 고친 뒤에는

Apps Script 코드를 바꾸면 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포**로 새 버전을 배포해야 반영됩니다. 이 경우 URL은 그대로입니다.

## 알아둘 점

- 웹 앱 URL은 페이지 코드에 들어가서 공개됩니다. 비밀번호 없이 쓰면 이 주소를 찾은 사람은 누구나 비용을 읽고, 추가하고, 지울 수 있습니다. 시트가 부풀지 않도록 비용은 500건까지만 저장됩니다.
- 비밀번호를 쓸 때는 약하면 추측당할 수 있으니 6자리 이상으로 정하세요.
- 잘못 지워진 비용은 구글 시트의 **파일 > 버전 기록**에서 되돌릴 수 있습니다.
- 처음 열 때 응답이 1~2초 늦을 수 있습니다.
- 이 저장소는 비용, 환율, 출발일만 저장합니다. 일정 수정, 예약 메모, 준비물 체크는 Claude 아티팩트에서만 됩니다.
